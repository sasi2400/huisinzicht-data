# HuisInZicht data

Public data and privacy policy for the **HuisInZicht** Chrome extension.

- `data/nvm.json`: regional housing-market figures per COROP region and house type (overbid vs asking price,
  share sold above asking, sale price per m², days to sell), extracted from the public quarterly
  *NVM Marktoverzicht* reports. Source: NVM / Brainbay. Refreshed automatically each quarter.
- [Privacy policy](PRIVACY.md)
